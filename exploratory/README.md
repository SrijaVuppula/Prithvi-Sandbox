# Exploratory Analysis

Self-initiated experiments extending the block masking study toward the paper
"Masking Geometry Matters." Not assigned by advisor — done independently to
build toward EarthVision/CV4EO submission.

1. complexity_stratified  — does scene complexity shift the crossover ratio?
2. distance_to_context    — per-patch error as a function of distance to visible context
3. fragmentation_spectrum — PSNR vs number of blocks at fixed mask ratio
4. real_cloud_masks       — validation under real cloud mask geometry
